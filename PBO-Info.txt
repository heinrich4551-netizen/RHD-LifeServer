RHD-LIFESERVER
PBO BUILD & INSTALLATION GUIDE
================================

Purpose
-------
This guide explains how to build RHD-LifeServer into an Arma 3 PBO and install it on an Arma 3 dedicated server.

Repository
----------
https://github.com/heinrich4551-netizen/RHD-LifeServer

Project
-------
Name: RHD-LifeServer
Framework: AsYetUntitled Framework v5.X.X (Git submodule)
Map: Altis
Author: LT. Toad


1. REQUIRED SOFTWARE
====================

Install these programs before building:

[1] Steam
    https://store.steampowered.com/

[2] Arma 3
    Install Arma 3 through Steam.

[3] Arma 3 Tools
    Install through Steam:
    Library > Tools > Arma 3 Tools

[4] Git
    https://git-scm.com/download/win

[5] MySQL/MariaDB
    Required for the upstream Altis Life persistence layer and the RHD extension tables.

[6] SimplePersist
    REQUIRED Steam Workshop dependency for RHD-LifeServer player-state persistence integration.

    Steam Workshop:
    https://steamcommunity.com/sharedfiles/filedetails/?id=3006691432

    Workshop ID: 3006691432
    Project: Toakan-Network/SimplePersist
    Copyright holder: Tom Daykin

    RHD does not redistribute SimplePersist source code. Install the published Workshop mod separately.


2. FIND ADDONBUILDER.EXE
=========================

RHD-LifeServer uses the AddonBuilder supplied with Arma 3 Tools.

A common installation location is:

C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder\AddonBuilder.exe

The repository build script expects the -ArmaToolsPath value to point to the folder that directly contains AddonBuilder.exe.

Example:

-ArmaToolsPath "C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder"

If your AddonBuilder.exe is installed somewhere else, use that folder instead.


3. DOWNLOAD THE RHD-LIFESERVER SOURCE
======================================

Open PowerShell and choose a development folder.

Example:

cd C:\
git clone https://github.com/heinrich4551-netizen/RHD-LifeServer.git C:\RHD-Development\RHD-LifeServer

Then enter the repository:

cd C:\RHD-Development\RHD-LifeServer


4. DOWNLOAD THE FRAMEWORK SUBMODULE
===================================

RHD-LifeServer keeps the upstream AsYetUntitled Framework as a Git submodule.

Run:

cd C:\RHD-Development\RHD-LifeServer
git submodule update --init --recursive

Verify that this directory exists:

C:\RHD-Development\RHD-LifeServer\framework\AsYetUntitled-Framework

Do NOT remove the framework directory or replace it with a copied/modified version.


5. INSTALL SIMPLEPERSIST FROM STEAM WORKSHOP
==============================================

RHD-LifeServer requires SimplePersist as an external Workshop dependency for player-state persistence.

Open the Steam Workshop page:

https://steamcommunity.com/sharedfiles/filedetails/?id=3006691432

Subscribe to the item and allow Steam to download it.

Confirm the mod is installed in your Arma 3 Workshop content before starting the server.

The dependency is:

@SimplePersist
Steam Workshop ID: 3006691432

The exact local folder name may be determined by the Workshop installation. Use the actual installed mod folder in your server's startup configuration.

SimplePersist is authored by Tom Daykin / Toakan-Network. Its source is licensed separately; RHD calls on the published Workshop mod and does not copy its source into this repository.


6. CHECK THE RHD ADDON SOURCE
==============================

The addon source must exist here:

C:\RHD-Development\RHD-LifeServer\addons\rhd_lifeserver

The important addon structure includes:

addons\
  rhd_lifeserver\
    config.cpp
    README.md
    config\
    functions\
    scripts\

If addons\rhd_lifeserver is missing, stop and correct the repository checkout before attempting the build.


7. ALLOW POWERSHELL SCRIPTS TO RUN
===================================

If Windows blocks the build script, open PowerShell and run:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Confirm the change if Windows asks.

This changes the policy for your Windows user account only.


8. BUILD THE PBO
================

From the repository root, run:

cd C:\RHD-Development\RHD-LifeServer

.\deployment\build.ps1 -ArmaToolsPath "C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder"

The script will:

- Find AddonBuilder.exe
- Read addons\rhd_lifeserver
- Build the addon
- Place the output in the dist folder

Expected output location:

C:\RHD-Development\RHD-LifeServer\dist\RHD_LifeServer.pbo


9. USE A DIFFERENT OUTPUT FOLDER (OPTIONAL)
============================================

You can choose another output directory.

Example:

.\deployment\build.ps1 `
  -ArmaToolsPath "C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder" `
  -OutputPath "C:\RHD-Builds"

The resulting PBO should be:

C:\RHD-Builds\RHD_LifeServer.pbo


10. SIGN THE PBO FOR A SERVER
============================

For a public or signature-protected server, create a private signing key with the Arma 3 Tools utilities.

Use:

DSSignFile.exe

and the key generated for your RHD-LifeServer addon.

The signed addon normally contains:

RHD_LifeServer.pbo
RHD_LifeServer.pbo.<your-key>.bisign

Keep the private .biprivatekey file secure.

Place the public .bikey file in the server's keys folder.

Example:

Arma 3 Server\keys\RHD_LifeServer.bikey

NEVER upload or distribute the private .biprivatekey file.


11. CREATE THE SERVER MOD FOLDER
================================

On the dedicated server, create:

@RHD-LifeServer\addons\

Copy the finished PBO into that folder:

@RHD-LifeServer\addons\RHD_LifeServer.pbo

If the addon is signed, also copy its .bisign file beside the PBO.

SimplePersist must also be installed on the server as a separate Workshop mod.


12. ENABLE THE MODS ON THE SERVER
==================================

Add both mods to the dedicated server startup parameters.

Example:

-mod=@SimplePersist;@RHD-LifeServer

If the actual Steam Workshop installation uses a different local folder name, substitute that installed folder name for @SimplePersist.

The RHD dependency manifest records SimplePersist Workshop ID 3006691432 as required.


13. SERVER CONFIGURATION
========================

The repository contains:

config\server.cfg
config\basic.cfg
config\RHD_LifeServer.hpp

Before starting the production server, replace the placeholder passwords in server.cfg.

Look for:

CHANGE_ME_ADMIN_PASSWORD
CHANGE_ME_COMMAND_PASSWORD

Do not publish real server passwords in GitHub.

The addon now loads RHD_LifeServer.hpp from its addon config, so the runtime settings are available through missionConfigFile.


14. DATABASE SETUP
==================

RHD uses the upstream Framework database adapter. Do not configure a second extDB3 connection for RHD.

1. Import the upstream Framework database schema:

framework\AsYetUntitled-Framework\altislife.sql

2. Apply the RHD extension schema to the same database:

database\rhd_extensions.sql

3. Confirm the upstream life_server extDB3 configuration is working.

4. Start the server and check the RPT for the RHD persistence initialization message.

RHD creates/uses the following additional persistent state table:

rhd_state

The table stores serialized RHD economy, contract and RP registries. Upstream player cash, bank and inventory persistence remains owned by the Framework.

SimplePersist is a separate player-state persistence layer and should be allowed to manage the player-state features supplied by that mod. RHD should not duplicate or overwrite SimplePersist's player loadout/health/position storage.

See database\README.md for the full persistence notes.


15. 3DEN SETUP
==============

RHD-LifeServer includes 3DEN modules so you can configure the RP systems directly in the Eden Editor.

New missions should use the RHD modules instead of manually creating old-style resource markers.

Available modules include:

RHD LifeCore
    Main configuration module.
    Configure farming harvest values, mining harvest values, civilian population, harvest cooldown and economy options.

RHD Resource Node
    Places a harvestable resource location.
    Configure the resource type, yield, radius, illegal status and enabled state.

RHD Processing Station
    Places a processing/refining location.
    Configure the processing class, station radius and enabled state.

Place the required modules in the Altis mission using Eden Editor.

Save the mission and test it before moving it to production.


16. MISSION CONFIGURATION INTEGRATION
======================================

The RHD addon cannot add new VirtualItems or ProcessAction classes to missionConfigFile after the mission has compiled.

For the requested RHD resources, add the repository fragments to the actual Altis Life mission configuration:

In Config_vItems.hpp, inside/alongside the existing VirtualItems definition:

#include "..\..\custom\RHD_vItems.hpp"

In Config_Process.hpp, inside/alongside the existing ProcessAction definition:

#include "..\..\custom\RHD_ProcessAction.hpp"

Adjust the relative path to your mission folder layout.

Do not modify the Framework submodule itself. Copy or link the RHD custom fragments into your mission source as part of your mission overlay.


17. CIVILIAN POPULATION
=======================

The default RHD configuration is designed around:

1 active player  = 115 civilians
Minimum          = 60 civilians
Maximum          = 115 civilians

The population system dynamically adjusts the civilian population as the number of active players changes.

The exact scaling can be changed through the RHD configuration or the RHD LifeCore 3DEN module.

19. TEST THE PBO
================

Start a local dedicated server or development server with:

-mod=@SimplePersist;@RHD-LifeServer

Load the Altis Life mission.

Check the RPT log for errors.

Then test:

[ ] SimplePersist loads without an addon/config error
[ ] RHD-LifeServer loads
[ ] Mission starts on Altis
[ ] RHD 3DEN modules initialize
[ ] F6 opens
[ ] F7 opens
[ ] F8 opens
[ ] Resource harvesting works
[ ] Resource processing works
[ ] Inventory updates correctly
[ ] Civilian population initializes
[ ] Economy initializes
[ ] RHD database extension loads
[ ] RHD state persists through a restart
[ ] SimplePersist restores its supported player state after reconnect
[ ] Server remains stable after several minutes


20. COMMON BUILD ERRORS
=======================

ERROR: AddonBuilder.exe not found

Cause:
The -ArmaToolsPath value does not point directly to the folder containing AddonBuilder.exe.

Fix:
Find AddonBuilder.exe and pass its parent folder.

Example:

-ArmaToolsPath "C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder"


ERROR: Addon source not found

Cause:
The repository does not contain addons\rhd_lifeserver.

Fix:
Verify that you cloned the correct repository and are running the command from the RHD-LifeServer checkout.


ERROR: Git submodule is empty

Fix:

cd C:\RHD-Development\RHD-LifeServer
git submodule update --init --recursive


ERROR: PowerShell script cannot run

Fix:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


ERROR: SimplePersist is missing

Cause:
The required Workshop dependency is not installed on the server.

Fix:
Subscribe/install Workshop item 3006691432:

https://steamcommunity.com/sharedfiles/filedetails/?id=3006691432

Then make sure its installed mod folder is included in the server startup -mod list.


ERROR: RHD persistence is disabled

Check the server RPT for:

RHD persistence disabled: upstream DB adapter was not available within 30 seconds.

Verify that the upstream life_server is loaded and extDB3 is configured correctly.


ERROR: Server does not load the addon

Check:

1. The folder is named exactly @RHD-LifeServer.
2. The PBO is inside @RHD-LifeServer\addons.
3. The startup parameter contains -mod=@SimplePersist;@RHD-LifeServer.
4. The PBO is not still sitting only in the development dist folder.
5. Check the server RPT log for the actual error.


21. REBUILD AFTER SOURCE CHANGES
================================

Whenever RHD-LifeServer source files are changed:

1. Pull the latest source:

cd C:\RHD-Development\RHD-LifeServer
git pull

2. Update submodules:

git submodule update --init --recursive

3. Rebuild:

.\deployment\build.ps1 -ArmaToolsPath "C:\Program Files (x86)\Steam\steamapps\common\Arma 3 Tools\AddonBuilder"

4. Replace the server's old PBO with:

dist\RHD_LifeServer.pbo

5. Restart the dedicated server.

=====================

dist\RHD_LifeServer.pbo

<Your Arma 3 Server>\@RHD-LifeServer\addons\RHD_LifeServer.pbo

-mod=@SimplePersist;@RHD-LifeServer


24. IMPORTANT SECURITY NOTES
============================

- Never commit server passwords to GitHub.
- Never commit .biprivatekey files.
- Keep the private signing key offline and secure.
- Use the public .bikey in the server keys folder.
- Keep verifySignatures enabled on production servers when appropriate.
- Test new builds on a development server before production deployment.
- Do not copy SimplePersist source into RHD-LifeServer without written permission from its copyright holder.
